# 路线图

记录宠物的成长数据是一件长期的事，所以这里的判断标准只有一条：**两年后还能不能安心用**。

## 已上线（v0.1 – v0.3）

- 登录鉴权、4 个 Tab、PWA（可加到主屏）
- 今日页：今日状态、7 天迷你指标、异常提示（连续软便 / 食欲差 / 呕吐 / 48h 未记录 / 体重下降）、疫苗与驱虫倒计时
- 快速录入：点选 + 一句话让 AI 预填（AI 只预填，确认后才入库）
- 数据页：体重 / 便便 / 食欲热图 / 呕吐，7·30·90 天区间，CSV 导出
- 记录页：疫苗 / 体内外驱虫 / 就诊，增删改，下次到期自动计算
- 档案页：猫信息、常去医院、账号、危险信号速查
- 每日自动备份（保留 14 份）

## v0.4 基础体验

- [x] **响应式**：平板两列、PC 左侧导航 + 宽内容区（现在只有手机布局）
- [x] **浅色主题**：跟随系统 / 浅色 / 深色三态，默认深色
- [x] **档案可编辑**：名字、生日、性别、绝育状态、备注（头像留到照片那一版）
- [x] **补记入口**：忘了记的时候，一眼能找到「补昨天」

## v0.5 多用户

- [x] 注册（邮箱 + 密码）
- [x] 邀请码绑定同一只宠物：`cat_members` 已是多对多，补一个一次性邀请码即可
- [x] 角色：owner（改档案、管成员）/ member（记录与查看）
- [x] **修复同日记录互覆盖**：`daily_logs` 唯一键 `(cat_id, log_date)`，两人同一天记录会静默覆盖 —— 加 `updated_by` / `updated_at`，合并时提示
- [x] 多猫切换（每台浏览器各记各的当前猫）

## v0.6 大模型自定义接入

- [ ] 设置页选择服务商（DeepSeek / 智谱 GLM / 通义千问 / Moonshot / OpenAI 兼容），自动填 `base_url` 与候选模型
- [ ] 用户填自己的 API Key + 选模型 + 「测试连接」通过才可保存
- [ ] Key 用 AES-256-GCM 加密存库（主密钥来自环境变量），界面只回显末四位
- [ ] **不共享站点密钥**：用户没配置自己的 key 时，明确提示去设置页填写，**绝不回退到站点环境里的 key**。理由很实际——站点以后可能推荐给亲友用，站长自己的额度不能被别人消耗。唯一例外是明确的站点管理员账号（显式开关，默认关闭）

## v0.7 长期记录的核心

- [ ] **照片**：便便 / 呕吐物 / 皮肤 / 就诊单据（`uploads/` 目录早已挂好，一直空着）
- [ ] **用药明细**：驱虫药名、剂量、当时体重（驱虫药按体重算，这是安全问题，不能只记「做过」）
- [ ] **复诊与疫苗提醒**：到期前主动提醒，不用打开 App 才知道
- [ ] **分享给兽医**：一键生成最近 7 天摘要（只读、可失效）

## 更远，但确定要做

- 多猫支持后的家庭视图
- 里程碑时间线（第一次剪指甲、第一次出门、绝育日）
- 周报 / 月报
- 离线记录（PWA 目前没有 service worker，宠物医院信号差时记不了）
- 记录搜索与筛选

## 不做

- 社区、论坛、晒图广场——这是私人记录工具，不是社交产品
- 自动诊断与用药建议——AI 只做录入，不做医疗判断
