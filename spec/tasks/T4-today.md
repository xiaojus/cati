# T4 今日页（监控面板）+ T5 快速录入

> 前置：T2/T3 已完成（登录、4 Tab 外壳、主题 token）
> 铁律：监控页**只读 + 只能新增**，不允许编辑/删除；只看最近 7 天；红黄绿判定只在这里。

## 要做的页面

`app/(tabs)/today/page.tsx`（服务端组件，`requireUser()` 后读取数据）

自上而下：

1. **煤球卡片**
   - 左侧：圆形头像位（无图时用黑猫剪影 + 两点金瞳的 SVG 占位）
   - 名字「煤球」+ 副标题（母 · 约 1 岁 · 隔离第 N 天，隔离起始 2026-11-11）
   - 右侧：最新体重（`weight_g` 最近一条非空，显示 kg 保留两位）+ 与上次对比箭头（↑/↓ + 差值）
2. **今日打卡状态条**
   - 今天有没有 `daily_logs` 记录；没有则显示珊瑚色提示「今天还没记」，有则显示薄荷色「已记录 · 记录人 xxx」+ 时间
3. **异常提示区**（有则显示，无则整块不渲染）
   - 连续 2 天 `stool_score >= 5` → 珊瑚：「连续 N 天软便」
   - 连续 2 天 `appetite <= 2` → 珊瑚：「连续 N 天食欲差」
   - 最近一次 `vomit_count > 0` → 琥珀：「最近有呕吐」
   - 超过 48 小时没有 `daily_logs` → 灰：「已 N 天没记录」
   - 体重比 7 天前下降 > 5% → 珊瑚
4. **7 天迷你指标**（4 个小卡：食欲 / 饮水 / 便便 / 精神）
   - 每个卡：今日值（大数字）+ 单位说明 + 最近 7 天 sparkline（纯 SVG，不引图表库）
   - 趋势箭头：与 7 天均值比较，±0.3 以内算持平
5. **待办倒计时**
   - 从 `records` 表取 `next_due` 最近的一条，显示「疫苗/驱虫 · 还有 N 天」，过期显示「已过期 N 天」珊瑚色
6. **底部悬浮按钮**「＋ 记一笔」（金瞳色，固定右下，44px+，点击弹出录入面板）

## 快速录入（同一个页面内，底部抽屉 / modal）

`components/QuickLogSheet.tsx`（'use client'）：
- 日期（默认今天，可改）
- 五组点选：食欲 1–5、饮水 1–5、便便 1–7、精神 1–5、呕吐次数 0/1/2/3+
- 体重（可选，克）
- 备注（可选，单行）
- 提交走 Server Action `app/actions/logs.ts` 的 `saveLog`：
  - zod 校验范围（appetite/water/energy 1–5，stool_score 1–7，stool_count/vomit_count 0–10，weight_g 500–15000）
  - **同日 upsert**：`ON CONFLICT(cat_id, log_date) DO UPDATE`，只更新本次提交的非空字段，`source='manual'`
  - 返回 `{ok, error?}`；成功后 `revalidatePath('/today')` 并关闭抽屉，触发猫爪动画
- 失败要显示中文错误，不要把异常吞掉

## 双面板边界（不许越界）

- 今日页不提供"编辑历史记录""删除记录""看 30 天曲线"
- 不显示记录表（疫苗/就诊列表）——只显示最近一条 `next_due` 倒计时

## 验收

- `npx tsc --noEmit`、`npm run build` 通过
- 用种子数据（14 天）打开 `/today`：能算出 7 天 sparkline、能触发「连续软便」判定
- 提交一条新记录后，同一天再提交一次**不产生第二行**（查 `daily_logs` 计数不变）
- 375px 宽无横向滚动
